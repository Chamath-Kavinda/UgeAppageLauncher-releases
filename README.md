# Uge Appage Launcher: Downloads

This page has the official installers for **Uge Appage Launcher**, a Minecraft launcher for the Uge Appage SMP.

## Download

1. Open the [**Releases**](../../releases/latest) page.
2. Under **Assets**, download one of the installers:
   - **`.exe`** (setup file): the easiest choice for most people.
   - **`.msi`**: the same launcher in a Windows Installer package, handy for managed or school computers.
3. Run the file you downloaded and follow the steps.

## Requirements

- Windows 10 or Windows 11 (64-bit)
- An internet connection for the first launch and for downloading game files

## Windows SmartScreen warning

The installers are not code-signed yet, so Windows may show "Windows protected your PC" when you run them. This is expected for a new app. Click **More info**, then **Run anyway**. Only download the launcher from this page.

## Updates

The launcher checks this page for newer versions. When one is available, Settings shows "Version X is available" with a button to open the download page. Updates are never installed automatically. You download and run the new installer yourself, and it replaces the old version.

## Problems or questions

Open an [issue](../../issues) in this repository or ask on the Uge Appage SMP community server.
